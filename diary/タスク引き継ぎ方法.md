# 日記のタスク引き継ぎ方法

## 方法1: 標準機能（手動コピー）

現在のテンプレートには「前日からの引き継ぎタスク」セクションが追加されています。

1. 新しい日記を作成すると、自動的に前日の日記へのリンクが表示されます
2. 前日の日記をクリックして開く
3. 未完了のタスク（`- [ ]` で始まる行）をコピー
4. 新しい日記の「前日からの引き継ぎタスク」セクションに貼り付け

## 方法2: Templaterプラグイン（自動化）

より高度な自動化を希望する場合は、Templaterプラグインをインストールしてください。

### セットアップ手順

1. Obsidianの設定を開く
2. 「Community plugins」→「Browse」で「Templater」を検索してインストール
3. 有効化後、設定で「Template folder location」を `.obsidian/templates` に設定
4. 日記のテンプレートを `.obsidian/templates/daily-with-tasks.md` に変更

これで、新しい日記を作成すると自動的に前日の未完了タスクが引き継がれます。

## 方法3: クイックアクション（推奨）

Obsidianのコマンドパレット（`Cmd/Ctrl + P`）から：
1. 「Daily notes: Open today」で今日の日記を開く
2. 前日の日記リンクをクリック
3. 未完了タスクを選択してコピー（`Cmd/Ctrl + C`）
4. 今日の日記に戻って貼り付け（`Cmd/Ctrl + V`）

## タスクの見つけ方

前日の日記で以下の形式のタスクを探してください：
- `- [ ] タスク内容` （未完了）
- `- [x] タスク内容` （完了済みは引き継がない）

完了済みのタスク（`- [x]`）は引き継ぎません。
