# 土木設計品質管理 ISO9001 機能設計ガイド

## 概要

土木設計DXプラットフォームがISO9001:2015適合と日本市場要件を満たすための機能設計ガイド。

**核となる4領域**：
- 文書管理（7.5条）
- 設計審査（8.3条）

- 変更管理（8.5.6条）

**日本特有要件**：照査技術者制度、電子納品要領、BIM/CIM原則適用

## 文書管理機能（ISO 7.5条）

### 版管理の実装要件

```
必須要素：
├── バージョン番号体系: Major.Minor.Patch（例：Ver 2.1.3）
├── 改訂履歴: 版数、改訂日、内容、理由、承認者
├── 命名規則: 文書番号-版数-改訂日（例：DOC-001-v2.0-20260110）
├── 最新版表示: システム上で自動識別・表示
└── 旧版管理: 「旧版」ラベル、アーカイブ移動、誤使用防止
```

### 「維持」vs「保持」の区別

| 区分 | 定義 | 対象文書 | システム要件 |
|------|------|----------|--------------|
| 維持（maintain） | 改訂可能、継続使用 | 品質方針、手順書、規定類 | 版管理、改訂ワークフロー |
| 保持（retain） | 変更不可、期間保管 | 検査記録、承認記録 | 改ざん防止、タイムスタンプ |

### 法定保管期間

| 文書種別 | 保管期間 | 根拠法令 |
|----------|----------|----------|
| 設計図書 | 15年 | 建築士法施行規則21条 |
| 完成図 | 10年 | 建設業法26条の3 |
| 打合せ記録 | 10年 | 建設業法施行規則26条 |
| 帳簿・契約書 | 5年（新築10年） | 建設業法40条の3 |

## 設計審査プロセス（ISO 8.3条）

### DR段階構成

| DR | 名称 | 審査内容 | 必須記録 |
|----|------|----------|----------|
| DR1 | 基本設計審査 | 設計条件、概略計画の妥当性 | 条件確認書、審査議事録 |
| DR2 | 詳細設計審査 | 構造詳細、数量の妥当性 | 計算書照査、図面チェック |
| DR3 | 最終審査 | 成果品の完全性、引渡し準備 | 照査報告書、納品チェック |

### レビュー・検証・妥当性確認の区別

```
Review（レビュー）
  └─ 問い: 要求事項を達成可能か？
  └─ 活動: デザインレビュー会議、設計審査会
  
Verification（検証）
  └─ 問い: 正しく作ったか？（Building the product right?）
  └─ 活動: 設計計算書照査、図面チェック
  
Validation（妥当性確認）
  └─ 問い: 正しいものを作ったか？（Building the right product?）
  └─ 活動: 現地検証、試験施工
```

### 設計インプット必須項目（8.3.3）

- 機能・パフォーマンス要求（道路幅員、耐荷重、設計速度）
- 過去案件情報（類似図面、失敗事例）
- 法令・規制要求（道路構造令、河川法、設計基準）
- 組織標準（社内設計標準、CADガイドライン）
- リスク（品質・安全リスクの潜在的結果）

## トレーサビリティ機能（ISO 8.5.2条）

### 文書識別コード体系

```
[プロジェクト番号]-[図面種別]-[連番]-[版番号]
例: PRJ2024-001-DWG-ST-0012-v2.0

種別コード:
  DWG-ST: 構造図
  DWG-PL: 平面図
  DWG-CR: 断面図
  CAL: 計算書
  SPE: 仕様書
  MTG: 協議記録
```

### 追跡関係マトリクス

| From | To | 管理方法 |
|------|----|----------|
| 設計計算書 | 図面 | 計算書番号を図面に記載、相互参照テーブル |
| 仕様書 | 図面 | 仕様書項目と図面の対応表 |
| 協議記録 | 設計変更 | 変更指示書番号と変更履歴の紐付け |
| 発注者指示 | 対応 | 指示番号による追跡 |
| 類似設計 | 現設計 | 流用元プロジェクトの識別 |

## 変更管理機能（ISO 8.5.6条）

### 必須記録3項目

1. **レビュー結果**: 変更の影響評価、リスク評価の結論
2. **承認者**: 変更を正式に許可した人の氏名・日時
3. **必要な処置**: 追加対策、是正処置、関係者への周知事項

### 変更承認権限マトリクス

| 変更区分 | 影響度 | 承認権限 |
|----------|--------|----------|
| 軽微 | 誤記訂正等 | 担当技術者 |
| 通常 | 設計内容に影響 | 主任技術者/照査技術者 |
| 重要 | 工程・コストに大きく影響 | 管理技術者/発注者 |
| 重大 | 安全・法令適合に関わる | 技術審査会/上級承認者 |

### 変更要因別管理ポイント

| 変更要因 | 管理ポイント |
|----------|--------------|
| 発注者変更 | 指示書番号での追跡、協議記録の保持 |
| 現場条件変更 | 変更前後の条件記録、影響範囲の評価 |
| 法令・基準変更 | 適用基準の明示、経過措置の記録 |
| VE提案 | 提案理由、採否判断の記録 |

## 日本特有要件サマリー

### 照査技術者制度

**資格要件**（いずれか）：
- 技術士（総合技術監理部門または該当部門）
- 国土交通省登録技術者資格
- RCCM（該当登録技術部門）
- 土木学会認定土木技術者（特別上級、上級、1級）

**責務**：
1. 照査計画を作成し業務計画書に記載
2. 業務の節目毎に成果の確認を実施
3. 成果物納入時の照査報告（赤黄チェック根拠含む）
4. 照査報告書を提出

### 電子納品要領

```
フォルダ構成:
INDEX_D.XML（業務管理ファイル）
├── REPORT/（報告書）
├── DRAWING/（図面）
├── PHOTO/（写真）
├── SURVEY/（測量成果）
├── BORING/（地質データ）
└── OTHRS/（その他）

命名規則:
- ファイル名: 半角英数大文字、8文字以内
- 拡張子: 3文字以内
```

### BIM/CIM原則適用（2023年度〜）

| LOD | 段階 | 品質管理への適用 |
|-----|------|------------------|
| 100 | 概略 | 位置・概形、初期合意形成 |
| 200 | 概略形状 | 構造形式確認、概略数量算出 |
| 300 | 外形表現 | 干渉チェック基礎 |
| 400 | 詳細表現 | 施工計画・積算、配筋確認 |
| 500 | 完成形状 | 維持管理段階での活用 |
